# Seed natural-query priors

The realism estimator measures the queries a category generates against a pool of phrasings real
users send; a category that drifts into stilted or overtly adversarial wording is penalised. The
pool is the engagement's own traffic, and an invented one measures our imagination.

`general-support/` is a rehearsal pool -- thirty generic customer-support openings in Spanish and
English -- so the local stack can run the exploitation stage end to end. Publish the client's real
traffic before reading any realism number from a run.
